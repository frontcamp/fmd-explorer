
Financial Market Data Analizer
==============================

FMD Analyzer — инструмент для визуализации и изучения мультипоточных финансовых данных, обогащённых аналитическими метаданными. Он работает с указанными потоками независимо от их происхождения: историческими, поступающими с биржи в реальном времени или синтетическими. Требования к формату входных данных находятся в файле /docs/input-data-format.txt
